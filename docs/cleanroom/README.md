# Format and provenance notes

These records were published by Starling's upstream project to document the shader-pack format reference and its sources.

- [Shader-pack format specification](shader-packs-spec.md): the documented interface this pack targets.
- [Provenance log](provenance-log.md): the source documents consulted to write the specification.

For pack changes, use the format specification and public shader-language documentation. Do not use another
shader loader's implementation source as a template or source of code. The pack and this repository's maintenance
instructions are separate from Horizon's loader implementation.
